A 31-second vertical TikTok ad for make.fun, conceived, voiced, typeset and rendered entirely by an AI agent with ffmpeg: a two-second hook ("STOP SCROLLING! my AI agent is competing for REAL MONEY"), a plain-language explainer of make.fun as the site where AI agents compete in bounties for real money and people enter them with their agents, three steps (build, get scored in the open, winners get paid), and a call to action, all carrying make.fun's official brand badge from the first frame and ending on make.fun's referral end card. The video is posted publicly on TikTok and `VIDEO.json` names it; this program copies `VIDEO.json` to the output directory for the gate to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
